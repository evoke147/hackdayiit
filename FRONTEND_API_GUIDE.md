# 🛰️ Antigravity API — Frontend Integration & JSON Schemas Guide

This document is the complete API contract between the **Antigravity Backend (powered by Gemma 4 via Gemini API)** and the Frontend. It contains all request/response JSON schemas, TypeScript interfaces, sample payloads for multiple student profiles, error schemas, and integration snippets.

---

## 📌 Quick Overview

- **Base URL**: `http://127.0.0.1:8000` (Local)
- **Content-Type**: `application/json`
- **CORS**: Enabled for all origins (`*`) in development
- **Underlying AI Model**: `gemma-4-26b-a4b-it`
- **Expected Latency**: **15 – 25 seconds** (Comprehensive generation by Gemma 4; frontend must display an engaging loading / progress state).

---

## 1. TypeScript Interfaces

Copy and paste these definitions directly into your frontend project (`src/types/roadmap.ts` or similar):

```typescript
export interface OnboardingData {
  degree_specialization: string;
  year_semester: string;
  subjects_studied: string;
  skills: string;
  programming_languages: string;
  career_goals: string;
  preferred_industry: string;
}

export interface IndustryRadar {
  topic: string;
  reason: string;
}

export interface LaunchPlan {
  profile_strengths: string[];
  missing_links: string[];
  next_30_days: string[];
  industry_radar: IndustryRadar;
}

export interface RoadmapResponse {
  model_used: string;
  launch_plan: LaunchPlan;
}

export interface TweakRequest {
  onboarding_data: OnboardingData;
  previous_plan: LaunchPlan;
  user_feedback: string;
}

export interface ApiErrorResponse {
  detail: string | Array<{ loc: string[]; msg: string; type: string }>;
}
```

### Endpoint B: Generate Launch Plan (`POST /roadmap`)

- **Route**: `POST /roadmap`
- **Headers**: `Content-Type: application/json`
- **Description**: Analyzes the onboarding profile and returns a structured Antigravity Launch Plan generated by Gemma 4.

#### Request Schema
| Field | Type | Required | Description |
|---|---|---|---|
| `degree_specialization` | `string` | Yes | Student's degree and major |
| `year_semester` | `string` | Yes | Current academic standing |
| `subjects_studied` | `string` | Yes | Comma-separated coursework |
| `skills` | `string` | Yes | Technical & soft skills |
| `programming_languages`| `string` | Yes | Comma-separated coding languages |
| `career_goals` | `string` | Yes | Target role, timeframe, company types |
| `preferred_industry` | `string` | Yes | Target industry sector |

## 3. Error Handling

### 1. HTTP 422 Unprocessable Entity
Occurs when required fields are missing or empty:
```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "degree_specialization"],
      "msg": "Field required",
      "input": {}
    }
  ]
}
```

### 2. HTTP 502 Bad Gateway
Occurs if the upstream Gemini API encounters an issue (e.g., quota exceeded or invalid API key):
```json
{
  "detail": "Gemma API error: 429 RESOURCE_EXHAUSTED"
}
```

## 4. Frontend Integration Snippets

### Using Modern `fetch` (JavaScript / TypeScript)

```typescript
const BASE_URL = 'http://127.0.0.1:8000';

/**
 * Generate Initial Roadmap
 */
export async function generateRoadmap(profile: OnboardingData): Promise<RoadmapResponse> {
  const response = await fetch(`${BASE_URL}/roadmap`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(profile),
  });

  if (!response.ok) {
    const errorData = await response.json();
    throw new Error(errorData.detail || `Server error: ${response.status}`);
  }

  return response.json();
}

/**
 * Tweak Existing Roadmap with Memory
 */
export async function tweakRoadmap(
  profile: OnboardingData,
  previousPlan: LaunchPlan,
  feedback: string
): Promise<RoadmapResponse> {
  const response = await fetch(`${BASE_URL}/roadmap/tweak`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      onboarding_data: profile,
      previous_plan: previousPlan,
      user_feedback: feedback,
    }),
  });

  if (!response.ok) {
    const errorData = await response.json();
    throw new Error(errorData.detail || `Server error: ${response.status}`);
  }

  return response.json();
}
```

## 5. UI Rendering Recommendations

| JSON Property | Suggested UI Treatment |
|---|---|
| `profile_strengths` | Render as 2 highlighted feature cards with positive badge (e.g. 🌟 "Strength") |
| `missing_links` | Render as 2 warning/focus badges (e.g. ⚠️ "Bridge This Gap") |
| `next_30_days` | Render as a numbered checklist or vertical timeline (1, 2, 3) |
| `industry_radar.topic` | Tag or bold heading in an accent color (e.g., cyan / violet) |
| `industry_radar.reason`| Explanatory callout text below the topic |
| `model_used` | Subtitle badge (e.g. "Generated by Gemma 4") to satisfy hackathon judging checklist |
